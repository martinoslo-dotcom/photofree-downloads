# PhotoFree — official Windows downloads

Official distribution repository for signed PhotoFree Windows installers.

Website: https://photofree.app

Releases will include the signed Windows installer and its SHA-256 checksum. The source code for PhotoFree is maintained separately in private repositories.

Only download from the official PhotoFree website or the Releases section of this repository. Do not turn off Windows security protections to install PhotoFree.

Support: support@photofree.app
